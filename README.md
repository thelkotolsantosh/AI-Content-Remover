# Repository wording cleaner

Simplifies repeated wording in Markdown and text files. Source code, configuration files, and fenced code examples are copied unchanged. The result is written to a separate folder.

```bash
python REMOVER.PY /path/to/repository /path/to/cleaned-copy
```

Choose an output folder outside the source repository. Python is the only runtime requirement.

```bash
python -m pytest -q tests
```
